# BizMaster Social Growth — אתר מרובה מסכים

## הפעלה
1. חלצו את קובץ ZIP.
2. פתחו את `index.html` בדפדפן מודרני (Chrome מומלץ).
3. אין צורך בהתקנה או בשרת כדי לבדוק את ממשק הדוגמה.

## מה כלול
- לוח בקרה בסגנון כהה עם כחול/ציאן, כרטיסי נתונים ורשתות חברתיות.
- ניווט בין לוח בקרה, יצירת קמפיין, חשבונות, קמפיינים, ניתוח, Premium והגדרות.
- טופס קמפיין, חלון אישור, חיפוש וסינון, מחיקת קמפיינים והודעות Toast.
- התאמה למובייל ולמחשב.

## חשוב
זהו ממשק Front-end: נתוני הסקירה הם נתוני תצוגה לדוגמה, וקמפיינים נשמרים בזיכרון הדף בלבד. אין בו התחברות אמיתית או שינוי מספרי עוקבים ברשתות. לשירות אמיתי יש לחבר Backend, מסד נתונים, אימות והרשאות API רשמיות לכל פלטפורמה. אין לבקש או לשמור סיסמאות של רשתות חברתיות.
